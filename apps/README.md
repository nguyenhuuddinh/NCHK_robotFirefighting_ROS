# Ứng dụng vận hành trên laptop

Thư mục `apps/` chứa giao diện và tài liệu ứng dụng của dự án. Các package
điều khiển ROS tiếp tục thuộc workspace/runtime hiện hành.

Ứng dụng đang phát triển: [Fire Robot Control](fire_robot_control/README.md).
